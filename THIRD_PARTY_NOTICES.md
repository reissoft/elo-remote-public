# Componentes de terceiros

Os assets de cada release incluem `libjuice-LICENSE.txt` e
`libjuice-source.tar.gz`, correspondentes à biblioteca nativa distribuída.
Os pacotes também usam dependências Python, Qt WebEngine/PySide6 no Windows
(a partir da versão 0.1.52), Qt/PyQt no Linux e bibliotecas multimídia, cujas licenças e avisos
continuam aplicáveis. Este repositório de distribuição não altera essas licenças
nem concede uma licença pública para o código-fonte proprietário do Elo Remote.

Qt/PySide6 são componentes de terceiros, distintos do Elo Remote. As permissões
dessas licenças, inclusive alterações e engenharia reversa permitidas para
depuração dessas alterações, permanecem aplicáveis aos componentes.
Informações, licenças e fontes correspondentes:

- https://doc.qt.io/qtforpython-6/licenses.html
- https://doc.qt.io/qt-6/qtwebengine-licensing.html
- https://download.qt.io/official_releases/QtForPython/
- https://download.qt.io/official_releases/qt/
