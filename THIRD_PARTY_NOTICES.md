# Componentes de terceiros

Os assets de cada release incluem `libjuice-LICENSE.txt` e
`libjuice-source.tar.gz`, correspondentes à biblioteca nativa distribuída.
A partir de 0.1.55, a interface usa Python/Tkinter, Tcl/Tk e Pillow,
sem Qt, Chromium ou WebView. Bibliotecas de mídia e demais dependências
continuam sujeitas às respectivas licenças. Este repositório de distribuição
não concede licença pública para o código-fonte proprietário do Elo Remote.

- pywin32: https://github.com/mhammond/pywin32/blob/main/Pythonwin/License.txt
- Python: https://docs.python.org/3/license.html
- Tcl/Tk: https://www.tcl-lang.org/software/tcltk/license.html
- Pillow: https://pillow.readthedocs.io/en/stable/about.html#license

## Pacotes anteriores

As versões 0.1.52–0.1.54 no Windows e as versões anteriores do Linux
usaram componentes Qt/WebEngine. Para esses pacotes, os avisos abaixo
continuam aplicáveis.

Qt/PySide6 são componentes de terceiros, distintos do Elo Remote. As permissões
dessas licenças, inclusive alterações e engenharia reversa permitidas para
depuração dessas alterações, permanecem aplicáveis aos componentes.
Informações, licenças e fontes correspondentes:

- https://doc.qt.io/qtforpython-6/licenses.html
- https://doc.qt.io/qt-6/qtwebengine-licensing.html
- https://download.qt.io/official_releases/QtForPython/
- https://download.qt.io/official_releases/qt/
